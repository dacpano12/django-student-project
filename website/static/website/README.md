# Student Portfolio Website

## Project Description
A student portfolio website built using Python, Django templates, HTML, and CSS.

## Purpose
To display student information, skills, school projects, and contact details.

## Features
- Home, About Me, Skills, Projects, and Contact pages
- Reusable navbar and footer
- Responsive layout
- Django template inheritance

## Technologies Used
Python, Django, HTML, CSS, Git, and GitHub

## Installation
1. Install Python and Git
2. Clone this repository
3. Create & activate virtual environment
4. Run: `python -m pip install -r requirements.txt`
5. Run: `python manage.py migrate`
6. Run: `python manage.py runserver`
